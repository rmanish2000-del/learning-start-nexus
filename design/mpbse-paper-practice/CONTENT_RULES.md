# Content Rules — Source Distinction

## Three content types — always distinct, never ambiguous

### 1. Official MPBSE Paper (green badge)

**What it is:** Actual board exam paper or official model paper published by MPBSE.

**Rules:**
- Link to `mpbse.nic.in` only — EduOS NEVER hosts the PDF
- Always opens in a new tab
- `aria-label` must say "opens in new tab"
- Disclaimer on every card: "External link · mpbse.nic.in · not hosted by EduOS"
- Year and paper code must come from verified MPBSE metadata only
- EduOS does NOT annotate, reformat, or re-render official question content
- EduOS does NOT score official papers directly (learner scores their own)

### 2. EduOS Original Practice (purple badge)

**What it is:** EduOS-authored questions written to follow the MPBSE pattern and blueprint.

**Rules:**
- Labelled "EduOS Practice" — never "Official MPBSE"
- Hosted and scored by EduOS infrastructure
- Bilingual where available (Hindi + English)
- Internal choices (आंतरिक विकल्प) replicated where present in actual MPBSE papers
- Mastery band scoring aligned to EduOS outcome taxonomy
- Questions are ILLUSTRATIVE — not copied from official papers
- Must not imply MPBSE affiliation or endorsement

### 3. Derived Exam-Pattern Intelligence (indigo badge)

**What it is:** AI/analytics-derived insights based on analysis of official MPBSE papers.

**Rules:**
- Labelled "Pattern Analysis"
- Disclaimer on every card: "AI-derived · not official MPBSE · verify against current blueprint"
- Source years must be cited: "Based on MPBSE papers 2019–2024"
- Never presented as official MPBSE guidance
- Must be re-validated each year when new papers are released
- Stale data (not updated for latest year) must be flagged

## Absolute prohibitions

- ✗ Host official MPBSE PDF files
- ✗ Present EduOS practice questions as "official MPBSE questions"
- ✗ Show fabricated statistics, pass rates, or improvement guarantees
- ✗ Reformat official question text with EduOS branding
- ✗ Present pattern analysis as official MPBSE guidance
- ✗ Imply affiliation with or endorsement by MPBSE
- ✗ Show real learner names or private learning data in any design or export
- ✗ Force CBSE paper structure onto MPBSE papers
- ✗ Publish Maths Basic/Standard split without MPBSE confirmation
